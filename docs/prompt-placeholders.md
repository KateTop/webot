# 提示词占位符

支持 {name} 助手名、{base} 已展开基础人设、{persona} 性格、{soul} 本次提供的记忆、{today} 本机日期、{history} 待整理/总结批次、{recent} 最近上下文、{max_chars} 记忆正文上限。

主动发言另支持 {my_recent} 上下文中可见的本账号消息和保守反馈、{allowed_moves} 允许动作。问答支持 {sender}、{question}。

基础人设中的 {base} 不可引用自身，会显示不可递归提示。未提供的变量显示“本场景未提供”；没有长期记忆时明确说明未读取。问答仍按需二次查询记忆，不因模板而自动加载全库。{history}和{recent}含时间、稳定成员ID和消息ID。{my_recent}不保证包含所有历史发言，没人艾特/引用不等于讨厌助手。

替换只做一遍，JSON花括号不变，注入资料里的占位符不再展开。双花括号{{name}}保留字面值。

自定义base替换默认基础人设，保留真实身份/资料隔离/执行结果约束。其他场景追加自定义规则；输出协议有优先级：主动发言JSON动作+正文或SKIP；记忆NO_UPDATE或changes/operations。空响应始终当作失败，不能推进游标。

五份适配模板在prompt-templates.json。初始四块骨架见initial-soul.md；只供新记忆使用，不覆盖已有soul。记忆数据仍由程序维护稳定ID与证据。

用户原稿的“空字符串”“完整重写”“沉淀新增推测”“直接承诺记住/遗忘”已改为现有可验收协议。没有实现语义自由归纳或任意删除。记忆上限和回复最大字数是两个参数。

Bot监视中的AI实际输入可以查看替换结果。本版示例会填入独立测试目录，旧目录提示词不改。
