# Bot 监视

启动监视版，在左栏打开“Bot监视”。收到新消息后选择记录，查看触发、规则、实际AI请求、生成及确认流程。支持群ID/状态筛选、每2秒刷新、暂停及清空。

“思考”展示可检查的规则依据、动作和SKIP；不展示模型隐藏推理，也不增加AI请求。艾特回答沿用正文协议，不为其编造判断摘要。

最近100条仅在本次进程内存中保留。每条最多80阶段、每阶段12000字符，截断有标记；高流量群可能快速淘汰旧记录。页面暂停不停止后台采集。清空后在途事件不会恢复旧记录。

后台记忆线程独立记录AI调用；AI返回不代表内容验收和记忆提交成功。手动重发、提醒不在消息链追踪范围，查看发送记录。非Windows后端可能停在待发送状态，不能据此断言送达。

监视接口限制本机访问和本机Origin。记录包含本机群聊和提示词，请按需要清空。程序不将监视内容写入普通日志或上传Git。

测试只使用合成消息；构建不等于真实微信收发验证。
