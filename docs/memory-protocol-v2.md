# 2026-10-09 记忆协议与主动发言测试版

## 测试前

完全退出旧版 WeBot，再打开新 EXE。端口 7327 被占用时新版拒绝启动，避免显示旧页面。窗口标题含“2026-10-09 记忆协议版”。安装目录不被覆盖。

新测试目录默认有独立配置和数据。若要使用旧群聊记忆，请在程序均关闭后自行备份并复制所需配置与数据到测试目录；不要把 API Key、聊天数据库或日志上传到 Git。这里没有自动移动或读取用户的运行数据。

## 迁移旧记忆

1. 打开记忆栏，选择群 → 迁移与版本。
2. 检查预览。迁移保留原措辞，按已有标题归类；没有标题的条目暂归“群里的事”，未知人物身份留空，不由模型猜测。需要人物归属时核对稳定成员 ID，并修改 `subject_id`、主题和区域。
3. 应用迁移会先保存旧正文快照，再写入四块结构。迁移前该群的旧格式自动写入会拒绝执行，不推进游标。
4. 编辑时保留 `[m…]`/`[o…]` 和末尾元数据。观察日期和来源在自动整理时由代码维护。普通手动编辑保留游标，保存旧版本变更时会拒绝覆盖。

四块为：每个人、群里的事、我说过的立场、观察中。正文与条目元数据一起保存在可编辑 soul.md，SQLite 保存副本、版本、进度和最多5个历史快照。

## 写入协议

- 每批读取仍为100条；默认有效消息门槛15条，可修改。纯媒体占位、短于4字符或无文字数字的消息不计有效消息。满100条的已结束批次可处理，避免稀疏有效信息被前面的无效消息永久挡住。
- `NO_UPDATE` 是唯一的模型无更新哨兵：响应须正常结束，首尾空白去除后精确匹配；只推进实际批次游标，不改正文。
- 空白、截断、不合格JSON、未知ID、未知证据和验收失败不推进。格式验收失败重试一次；接口故障按AI池预算重试和轮换。
- 有变化时模型返回最多6项变更。代码保留旧条目，分配新ID、检查身份和证据，拒绝普通写入异常缩水；不再让模型重写全部ID和日期。默认正文上限2000字，元数据另有12000字符上限。
- 观察引用当前批消息ID，由对应时间戳计算日期；不同日期去重。已有观察升级至少需要3个不同日期，不采纳模型自报次数。
- 上一批最多5条仅作理解上文，不允许作为本次新证据。
- 明确艾特“记住/记一下…”可以立即写入本人记忆，不受条数门槛限制；这条独立写入不跳过此前未处理的聊天游标。
- 原有后续段确认机制保留。慢速群默认6小时兜底，排除触发时刻最近10分钟；有效消息不足继续等待。成功游标只到实际处理末条。

## 五类指令与主动发言

基础人设和具体品味共用于主动、艾特/引用。AI配置可编辑基础人设、品味、主动指令、问答指令；记忆栏可编辑写入和沉淀补充规则。输出协议由代码强制，补充指令不能改变协议。

主动模型返回动作+正文的JSON或SKIP。动作不在允许范围直接丢弃，不改写重发；默认仅追问、带细节的回应。超长正文不截断发送。艾特/引用每群每人每分钟默认3次，超限静默，不刷提示。发送延迟默认1–3秒，可调；它只是节奏控制。

## 发送、立场与提醒

Windows先记录发送前的微信库边界，完成RPA后最多等待12秒。只接受目标群中新出现、本账号、时间和正文对应的消息；缺少本账号ID、超时或未匹配均标“未确认”。未确认不自动重复发送。

所有确认消息进入聊天日志；仅确认的表态/反对作为助手立场的整理来源。初期只允许追问和细节回应，立场区为空正常。主动额度与反馈从确认发出后开始，发送失败不记立场。

提醒只接受明确艾特/引用请求，例如“提醒我 2026-10-10 12:00 喂猫”。模糊时间会请用户明确；确认复述在微信库中发出后才启用。后台约每30秒检查，停机或发送排队可延迟。一次发送后标确认或未确认；进程在发送途中退出会保留sending状态，不自动再次发送，须人工核对。聊天提取的普通待办不自动提醒。

“提醒与发送状态”可查看、刷新状态，取消尚未发送的提醒，并查看记忆操作记录。未确认代表观察不足，不能据此断言消息没有发出。

## 遗忘与沉淀

明确命令“忘掉/忘记/别记/不再记录/删掉…”仅选择请求人稳定ID所属条目。身份不明的迁移条目、第三方条目不能通过聊天直接删除。删除先安装读取/写入屏蔽，再清正文与快照；清单只留成员ID和粗粒度主题，可在“不再记录”编辑。

原始聊天库和已发聊天消息不属于记忆删除范围。不能安全按身份清理的旧格式快照会被清空，避免其中仍留有被遗忘内容。主题同义表述识别仍有局限，需检查清单与后续整理结果，不声称彻底清除所有语义等价信息。

沉淀在本机0–6点、群沉寂30分钟后最多每天一次；正文没有新变化且没有过期观察时跳过。观察超过30天未出现由代码删除。模型只能提出按ID删除/合并/抽取原文压缩，不能自由新增事实；合并不能跨人物和区域。手动沉淀使用相同规则。操作日志保留动作与ID，不把遗忘细节写进日志。

## 验证边界

合成SQLite/模型响应测试覆盖进度、截断、ID、证据、版本冲突、遗忘权限、快照、动作、发送确认和提醒许可。前端与PyInstaller构建不等于真实微信送达验证。没有在本次开发中向真实群发送测试消息，也没有自动迁移用户的运行数据。单实例运行；不承诺跨文件与SQLite在突然断电时完全原子。
